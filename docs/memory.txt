Zeropage Usage
==============

$35 - $3f (11 bytes), saved and restored by every call that uses them.
Defragmentation callbacks must not use them.


IO2 RAM ($df00 - $dfff)
=======================

$df00 - $df7f  libefs: jump table, bank in/out code, generic command,
               variables (see docs/architecture.md)
$df80 - $dfff  EAPI jump table (EFS_init_eapi) or MiniEAPI


Internal States (internal_state)
================================

$00: no channel open
$01: a command (scratch) finished; only EFS_close is valid
$80 | state: file open for reading
$c0 | state: file open for writing
$40 | state: directory open for reading (state = dirlist state)


Configuration
=============

Configuration starts at 00:1:1b18, see docs/manual.md ("Configuration")
and the struct libefs_config in src/lib/lib-efs.i.


Directory
=========

256 entries of 24 bytes per area ($1800 bytes):
  00-15  name, padded with $00
  16     flags: bits 0-4 type ($1f: unused), bit 7 hidden; $ff: blank
  17     bank
  18     reserved
  19-20  offset, relative to the files address of the area
  21-23  size (24 bit), including the 2 byte load address
At most 255 entries are used; slot 255 stays blank (terminator). Its
name bytes 0 and 1 hold the defragmentation markers "copy started"
(source) and "copy complete" (destination), see docs/architecture.md.

=====================================

00:1:0000      area 0 directory
     ...
     1700      area 0 directory
     1800      EAPI
     1900      EAPI
     1A00      EAPI
     1B00      easycart name & libefs configuration
     1C00      loader
     1D00      loader
     1E00      loader
